# Image Placement Instructions

Please save your images to the following locations:

## Logo
- **File:** `logo.png` (the circular Yum Plushies logo)
- **Location:** `/assets/images/logo.jpg`
- **Recommended size:** 400x400px or larger (will be displayed at ~180px)

## Image Requirements
- Format: JPG or PNG
- Recommended size: 800x800px minimum for plushies
- Images should be well-lit with clean backgrounds
- Square aspect ratio works best

## How to Add Images
1. Drag and drop your images into the `/assets/images/` folder in VS Code
2. Rename them to match the filenames above
3. The website will automatically display them

---

**Note:** The website is fully functional without images - placeholders will show until you add your actual photos.
